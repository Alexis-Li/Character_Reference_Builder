# ADR 0001：以 Node Banana 为最小闭环原型起点

日期：2026-09-10。

状态：**采纳用于下一阶段原型；尚未通过生产准入。** 本决定不等于云端模型、OAuth 或本地 SAM 已选定并验证。

## 背景与证据

项目优先复用成熟成果，主路径是部件参考生成与连续优化。需要画布、标注、多输入、比较、保存和失败恢复，但也必须保护原画依据、人工选定结果和费用范围。

[执行报告](../validation/minimum-loop-2026-09-10.md)显示固定 Node Banana 快照可安装、构建及在 Windows 启动；客户端生成链与真实文件接口可用。同时，需求探针发现多参考静默丢失、一般错误自动回退、失败清空和重跑覆盖四项不兼容行为。

## 决策

### 应用底座

从 Node Banana `5c0e0ae6150f29a6de819f8d6f1dedba15151f7c` 建立受控二次开发基线，保留来源和许可证。该固定快照已在 CRB-01 导入产品源码；外置临时目录中的原始候选快照只作为复跑证据，不是另一份产品源码。

复用 TypeScript、React、Next.js、本地 WebUI、React Flow、Zustand 和 Konva。首先保留上游锁文件的已构建版本，不同时升级全部依赖。状态管理库可复用，但不把上游通用 workflow store 直接当作角色项目领域模型。

保留可见的业务任务节点与最小路径。音频和视频永久不属于产品范围；上游相关节点、执行器、API、依赖和测试仅作为待清理的迁移残留，不得恢复为入口或后续能力。LLM 用于视觉理解与推理，ComfyUI 只作为待验证的可选执行适配，不与音视频一并裁剪；外部 3D、社区及收费工具入口仍不进入首个原型导航。以实际引用关系安全缩减依赖，避免把“产品不需要”误写成“当前已经完全解耦”。首阶段使用本机回环地址服务；面向用户的 Launcher 作为首批交付任务，不将手工终端当作最终使用方式。

### 业务、调用和资产边界

- 业务任务持有设计依据、部件、视图、约束和修改范围，只声明需要的能力。
- Provider 适配器负责真实入口的输入和输出限制。必须检查参考数量和编辑支持；不能只修改 base URL 或模型名称就假定兼容。
- 一次运行记录与人工选定结果分开；重跑追加候选，选择由用户更新。下游引用明确的候选版本，不能跟随“最新输出”静默漂移。
- 本地项目采用带版本的清单与独立图片文件作为原型保存形式，路径相对项目根目录；使用稳定资产标识、可核对的内容哈希和原子保存。上游保存代码可复用，领域字段与可迁移语义需补充。不在本轮引入数据库作为前提。
- 云端请求使用显式状态，区分明确未执行失败与结果未知。未授权新增费用或无法控制预算时不自动付费；关闭上游通用自动回退，待专用规则通过测试后再开放。
- 基础本地裁切、标注和比较优先复用浏览器工具；SAM 后续独立验证。尚未决定 SAM 版本、Python 推理服务或完整 ComfyUI 运行环境，不因已有接入入口而自动引入。

### Provider 结论

官方 OpenAI 图像 API 和 Gemini API 作为首批接口适配候选，首个真实调用由可用账号及用户认可成本决定，质量结果再决定项目默认组合。**当前没有“最佳出图模型”结论。**

`openai-oauth` 有多参考编辑源码，作为实验路径优先于原样 `chatgpt-bridge`；其 mask 不受支持，账户能力仍未实测。`chatgpt-bridge` 默认参考提示与设计保真目标存在冲突，不直接纳入首个生产适配器。详见[Provider 证据](../research/provider-feasibility-2026-09-10.md)。

## 其他方案与取舍

| 方案 | 本轮判断 |
| --- | --- |
| Node Banana 原样加工作流模板 | 不采用。模板无法修正服务端丢参考、回退和候选版本契约 |
| 基于 Node Banana 有边界地二次开发 | 采用为原型起点。已有安装、构建、数据流和文件证据；代价是维护上游差异，需收窄通用功能 |
| 仅取 React Flow 从零组装 | 保留为退出方案。领域结构更自由，但需重新完成标注、保存、比较和执行等通用能力；本轮未实现此替代原型，投入判断为推论 |
| 完整 ComfyUI 作为首版必装底座 | 本轮不选定。默认路径无需本地生成链，SAM 尚未测；缺少证明其安装与维护负担值得的任务数据，并非否定其本地工具复用价值 |

## 准入与重新决策条件

首个可供真实资料测试的原型必须：P01–P07 需求探针对应行为全部通过；Windows 文件路径和项目迁移通过；禁用未授权付费回退；多参考实际请求符合所选入口；既有选定结果在失败与重跑后不丢失。

完成真实 Q01–Q04 与人工评审前，只能称原型，不能称生产可用。若上述领域要求必须持续改动大量无关通用执行代码、原型无法保持核心回归，或真实任务没有可接受的质量／成本组合，重新比较组件级复用及更换 Provider。保留项目资料与导出契约，使更换底座不迫使用户重建角色资产。
