## 已交付行为

- 保存时为原画和候选建立版本化资产清单。每项使用稳定逻辑标识、独立资产文件、项目相对引用、SHA-256、字节数和 MIME 类型；候选身份与可复用媒体文件身份分开记录。
- 角色项目始终使用独立资产文件。项目 JSON 与图片都先写临时文件，再以可恢复替换提交；保留上一有效项目作为中断恢复依据。读取和项目列表也能识别提交间隙留下的上一版本。
- 项目文件剔除保存目录和凭据字段，并清理数据中的绝对本机路径。复制整个项目目录后，以新目录为基准校验和加载相对资产引用。
- 打开项目时逐项核对清单。单张图片缺失或哈希不符会给出汇总提示，领域关系、人工选择及其余资产保持不变。
- 单部件工作区可先保存再导出参考包。默认只导出人工选定且已批准的原始候选；用户可显式包含已选但未批准的候选，清单和说明保留实际审核状态。
- 参考包包含独立图片、SVG 总览、部件与视图说明、有效要求、推测内容、审核状态和资产清单。没有 SAM 或 Mask 时可正常导出；只有实际存在且显式选择的 Mask／透明提取资产会进入参考包。
