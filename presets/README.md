# 产品预设

这里存放随产品版本管理、可复用的内容定义。已提供 `workflows/part-reference.json` 默认单部件预设，由首页“单部件参考工作区”加载。预设填写设计保持要求并选择正面，不自动提交云端请求，不覆盖历史候选；其他子目录的占位文件不代表已实现的能力。

| 目录 | 内容 | 草案中的候选示例 |
| --- | --- | --- |
| `workflows/` | 用户可加载、修改和保存为副本的工作流预设 | 完整角色流程、仅多视图、服装拆件、部件参考、细节恢复 |
| `prompts/` | 可插入不同生产步骤的通用自然语言约束 | 保持原设计、不添加装饰、保留指定层级 |
| `references/` | 约束部件参考呈现方式的模板 | Garment Turnaround、Object Turnaround、Detail Sheet |

预设不得包含真实凭据、用户私有图片或某次生成的临时结果。用户修改后的角色项目与运行数据归根目录 `data/`；应用图标等静态素材归 `assets/`。

预设路径、可选分支及范围统一见[产品需求第 4.5 节](../docs/product-requirements.md#45-工作流预设)。首批交付单部件预设；具体内容根据开发顺序逐步加入，沿用 `CONTEXT.md` 中的领域术语。
